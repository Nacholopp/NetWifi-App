NetWIFI

This project consists of the development of a microservices-based application for the 
estimation and predictive analysis of Wi-Fi coverage in indoor environments. From nothing 
more than the floor plan of the environment and the position of the access points, a U-Net 
deep learning model generates an estimated coverage map, obtained with an average error 
below one decibel and almost instantaneously, bringing to the general public a capability so 
far reserved for professional tools.
